# Documentation screenshots

The main README uses `sign-in.png`, `dashboard.png`, `marking-desk.png` and
`student-access.png`, captured from the running application with Chromium.
They are unretouched application captures, not concept mockups.

Source data: the isolated fictional school seeded by `scripts/e2e_server.py`.
No production school records or real student credentials are shown. The teacher
account is the existing test fixture; no PINs are generated for these captures.
Mock AI warnings remain visible. The sign-in animation is illustrative.

Capture settings: 1440 × 1000, device scale 1, reduced motion, loaded local fonts;
student-access uses a 1440 × 620 viewport. Routes: `/signin`, `/`,
`/exams/1/review/1`, and `/student-access` with Form 5A selected.

`page-check-fr.png` is a historical screenshot and is not part of the current
README tour.
